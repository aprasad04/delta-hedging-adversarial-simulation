# Delta Hedging and Adversarial Stock-Path Simulation

A quantitative-finance research project that evaluates discrete-time delta hedging for European options under baseline, stressed, and adversarially generated market paths.

The project brings together analytical option pricing, Monte Carlo simulation, risk measurement, and PyTorch-based learning in one reproducible notebook.

## Highlights

- Black–Scholes pricing engine with delta, gamma, vega, theta, and Newton–Raphson implied-volatility estimation.
- Monte Carlo price-path generation using geometric Brownian motion (GBM).
- Stress scenarios combining jump diffusion and stochastic volatility.
- Discrete-time delta-hedging engine with proportional and fixed transaction costs.
- LSTM hedge-ratio model trained with a CVaR-based objective.
- Differentiable adversarial market-path generation using PyTorch autograd.
- Comparative risk analysis using P&L, VaR, CVaR, skewness, and kurtosis.

## Methodology

1. Load the supplied NIFTY market data and derive the spot reference and realised-volatility input from futures observations.
2. Price an at-the-money European option and compute Black–Scholes Greeks.
3. Simulate GBM, jump/stochastic-volatility stress, and adversarial price paths.
4. Rebalance a short-option delta hedge at several frequencies while accounting for transaction costs.
5. Train an LSTM hedge-ratio model using a CVaR-based loss and compare the simulated P&L distributions.
6. Summarise tail risk through Value at Risk (VaR) and Conditional Value at Risk (CVaR).

## Setup

Use Python 3.9 or later.

```bash
python -m venv .venv
```

Activate the environment:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch the notebook:

```bash
jupyter notebook Delta_Hedging_Adversarial_Simulator.ipynb
```

Run the cells from top to bottom. The notebook automatically detects the included CSV files and writes generated figures to `plots/` when executed.

## Configuration

The `CONFIG` dictionary near the beginning of the notebook centralises the model inputs, Monte Carlo settings, rebalancing frequencies, transaction-cost assumptions, LSTM settings, and adversarial-training settings. The included defaults use an at-the-money, 30-day NIFTY call-option scenario.

## Outputs

The notebook produces price-path visualisations, hedging P&L distributions, rebalancing-frequency comparisons, transaction-cost analysis, adversarial-path analysis, and a final risk-metrics table.

## Sample Results

The following results were generated by the included notebook for its 30-day, at-the-money NIFTY scenario. The direct GBM comparison uses 10,000 paths, 252 hedge rebalances for both strategies, and identical transaction-cost assumptions (10 bps proportional cost plus ₹0.50 fixed cost per rebalance).

| Strategy / scenario | Mean P&L (₹) | Std. P&L (₹) | VaR (5%) (₹) | CVaR (5%) (₹) |
| --- | ---: | ---: | ---: | ---: |
| Black–Scholes delta hedge — GBM | −270.07 | 55.92 | −370.41 | −397.58 |
| LSTM hedger — GBM | −198.54 | 41.85 | −261.66 | −280.45 |
| Black–Scholes delta hedge — stress paths | −219.46 | 257.28 | −718.74 | −952.72 |
| Black–Scholes delta hedge — adversarial paths | −3.18 | 19.90 | −37.16 | −52.58 |

Under the matched-cost GBM configuration, the LSTM hedge produced approximately 29% lower VaR and CVaR than the 252-rebalance Black–Scholes benchmark. This is an in-sample simulated comparison; see the limitations below.
